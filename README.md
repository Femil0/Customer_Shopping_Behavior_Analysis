# 📊 Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow, covering the entire process from raw data preparation to business insight generation. The analysis was performed using Python for data processing and exploratory analysis, SQL Server for querying the data, and Power BI for building an interactive dashboard. The final findings were documented in a report and presented using Gamma.

---

## Project Objectives

- Explore and understand the dataset through Exploratory Data Analysis (EDA).
- Clean and prepare the data for analysis.
- Perform SQL analysis to answer business-related questions.
- Build an interactive Power BI dashboard.
- Present insights through a professional report and presentation.

## Project Workflow

### 1. Data Loading
- Imported the dataset into Python.
- Inspected the data structure and identified data types.

### 2. Exploratory Data Analysis (EDA)
- Generated descriptive statistics.
- Identified trends, distributions, and correlations.
- Created visualizations to better understand the data.

### 3. Data Cleaning
- Removed duplicate records.
- Handled missing values.
- Fixed inconsistent data.
- Converted data types.
- Prepared the dataset for further analysis.

### 4. SQL Analysis
- Imported the cleaned dataset into SQL Server.
- Wrote SQL queries to answer analytical and business questions.
- Used filtering, aggregation, grouping, and sorting techniques.

### 5. Dashboard Development
- Connected Power BI to the processed dataset.
- Created interactive visualizations and KPI cards.
- Designed dashboards to communicate key insights effectively.

### 6. Reporting
- Summarized findings in a written report.
- Created a presentation using Gamma to communicate results.
